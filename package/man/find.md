#### Description

`find` routes to the `cloud-find` profile, whose `ask` command is the actual command finder. `aux4
find "<query>"` is shorthand for `aux4 cloud-find ask "<query>"`.

#### Usage

```bash
aux4 find "<query>"
```

#### Example

```bash
aux4 find "list my Slack channels"
```
