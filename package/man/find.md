#### Description

`find` routes to the `cloud-find` profile. Its `ask` command is the actual command finder — see
`aux4 aux4 man find ask`. There is no bare `aux4 find <query>` form; always call `aux4 find ask
"<query>"`.

#### Usage

```bash
aux4 find ask "<query>"
```

#### Example

```bash
aux4 find ask "list my Slack channels"
```
